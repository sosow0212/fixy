# 레벨 시스템 — 수박게임

> 작은 개인 관찰이 쌓여 한 단계씩 합쳐지고, 결국 전 팀원이 공유하는 코어가 된다.
> 같은 종류의 "불만/배움"이 모일수록 더 단단하고 공통적인 지식으로 승급한다.

```
   L1 에피소드 ──(유사한 게 N개)──▶ L2 스킬 ──(M회 재사용)──▶ L3 공통 스킬
        │                                                        │
   개인/로컬                                              (같은 태그 K개)
                                                                 ▼
                                                  L4 팀 규칙 ──(안정화)──▶ L5 코어
                                                   (사람 승인)            (사람 승인)
```

## 각 레벨

### L1 — 에피소드 (개인, 자동)
- **무엇**: 매 작업 1건 = `{프롬프트, 신호, 태그, 만진 파일}`. 사용자의 불만·교정도 신호로 기록.
- **어디**: `memory/episodes.jsonl` (append-only, `.gitignore` — 공유 안 함)
- **어떻게**: `fixy-recorder` 플러그인이 `session.idle` 마다 자동 기록. `fixy_note` 로 수동 핀도 가능.
- **신호**: `complaint`(불만) · `correction`(교정) · `insight`(깨달음) · `success` · `note`

### L2 — 스킬 (개인 → 팀)
- **무엇**: 재사용 가능한 절차/런북 (`SKILL.md`)
- **진입**: 유사 L1 이 `minEpisodes`(기본 3)개 이상, 태그 유사도 `minTagOverlap`(0.34) 이상
- **어떻게**: `/fixy-evolve` → `fixy_digest`(결정론적 클러스터링)로 후보를 잡고 `fixy_promote` 로 작성. 그 L1 들은 "승급됨" 표시.
- **공유**: `/fixy-share` → `fixy/skill-*` 브랜치 + PR

### L3 — 공통 스킬 (팀)
- **무엇**: 충분히 검증된, 팀이 함께 쓰는 스킬 (scope: team)
- **진입**: L2 스킬이 `minUses`(기본 5)회 이상 `fixy_recall` 로 재사용됨
- **어떻게**: `fixy_levelup <스킬>` (자동, 승인 불필요) → upstream PR 권장

### L4 — 팀 규칙 (팀, 사람 승인)
- **무엇**: 한 주제로 모인 L3 스킬들의 공통 원칙 → `rules/team-<주제>.md`
- **진입**: 같은 태그의 L3 가 `minSkills`(기본 3)개 이상
- **어떻게**: `/fixy-level-up` 이 규칙 초안을 **제안** → 사용자 승인 후에만 작성 → upstream PR
- ⚠️ 자동 적용 금지

### L5 — 코어 헌법 (전 팀원, 사람 승인)
- **무엇**: 불변 원칙. `rules/core.md`. `instructions` 로 모든 작업에 주입.
- **진입**: L4 규칙이 안정화되어 전 팀원 합의급
- **어떻게**: `/fixy-level-up` 이 diff 제안 → 명시적 승인 후에만 → upstream PR
- ⚠️ 전 팀원 영향. 가장 신중하게.

## 임계치 조정

`fixy.config.json > levels`:

```json
{
  "levels": {
    "l1ToL2": { "minEpisodes": 3, "minTagOverlap": 0.34 },
    "l2ToL3": { "minUses": 5 },
    "l3ToL4": { "minSkills": 3 },
    "requireHumanApproval": ["l3ToL4", "l4ToL5"]
  }
}
```

## 왜 레벨을 나누나
스킬을 무제한으로 만들면 "개판 오분전" — 비슷한 스킬이 난립해 무엇을 믿을지 모르게 된다.
레벨은 **증거의 양으로 신뢰도를 표현**한다: 한 번 본 것(L1)은 가볍게, 반복 검증된 것(L3+)은 무겁게. 낮은 레벨에서 노이즈를 걸러내고, 올라갈수록 적고 단단한 공통 지식만 남긴다.

## 개인 vs 팀
- **L1~L2**: 개인적. 내 작업 패턴·내가 받은 불만에서 나온 것.
- **L3**: 팀 공통 스킬. 여러 번 쓸모를 증명한 것.
- **L4~L5**: 팀 규칙·코어. 모두가 따르는 약속 — 그래서 사람 승인이 필요.
