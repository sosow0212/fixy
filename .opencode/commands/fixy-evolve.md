description: 아우터 루프 — L1 에피소드를 분석해 L2 스킬로 승급
agent: fixy
---
자가개선 아우터 루프를 실행한다. (수박게임: 흩어진 L1 관찰들을 모아 L2 스킬로 합친다.)

1. `fixy_digest` 로 미승급 L1 클러스터(승급 후보)를 가져온다.
2. 각 후보에 대해 판단한다:
   - 불만/교정이 반복된 주제 → 같은 실수를 막는 **런북/체크리스트 스킬**
   - 인사이트가 반복된 주제 → 재사용 가능한 **절차 스킬**
   - 노이즈(일회성·맥락 의존)는 건너뛴다.
3. 승급할 후보마다 `fixy_promote` 를 호출한다 — name(kebab-case)·description·body(언제 쓰는지 + 단계별 절차)·tags·episodeIds 를 채운다. body 는 다음에 그대로 따라 할 수 있을 만큼 구체적으로.
4. 끝나면 `fixy_status` 로 현황을 보여주고, 공유할 만한 스킬은 `/fixy-share` 를 권한다.

추가 지시(선택): $ARGUMENTS

생성한 스킬 목록과 각 근거를 한국어로 간결히 보고한다.
