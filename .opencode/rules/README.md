# rules/ — 규칙(L4/L5)의 단일 출처(SSOT)

- `core.md` — **L5 코어 헌법**. 전 팀원 불변 원칙. opencode `instructions` 로 자동 주입. 개정은 사람 승인 필수.
- `self-improvement.md` — 자가개선 레벨 승급 규약. 에이전트가 따르는 학습 프로토콜.
- `team-*.md` — **L4 팀 규칙**. L3 스킬들이 한 주제로 모이면 `/fixy-level-up` 으로 승격해 생성한다(사람 승인).

규칙을 바꾸려면 이 디렉토리의 파일만 고친다. 에이전트 프롬프트(`agents/fixy.md`)는 핵심을 요약해 담고, 상세는 여기를 Read 한다.
