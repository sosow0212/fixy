description: 메타 루프 — 스킬을 상위 레벨로 승급 (L2→L3, L3→L4 규칙, 사람 승인)
agent: fixy
---
지식의 레벨 승급을 진행한다. 대상: $ARGUMENTS

먼저 `fixy_status` 로 승급 후보를 확인한 뒤, 대상 레벨에 따라:

**L2 → L3 (팀 공통 스킬)** — 재사용 임계 충족 시
- `fixy_levelup <스킬명>` 호출. 자동 승급(사람 승인 불필요).

**L3 → L4 (팀 규칙)** — ⚠️ 사람 승인 필수
- 같은 태그로 모인 L3 스킬들의 공통 원칙을 뽑아 `.opencode/rules/team-<주제>.md` 규칙 초안을 **제안**한다.
- 사용자에게 초안을 보여주고 **승인을 받은 뒤에만** 파일을 쓴다.
- 승인되면 규칙 파일을 만들고, 통합된 L3 스킬들에는 "이 규칙으로 승격됨" 메모를 남긴 뒤 `fixy_share` 의 extraPaths 에 규칙 파일을 포함해 PR 한다(target=upstream 권장).

**L4 → L5 (코어 헌법)** — ⚠️ 사람 승인 필수
- `rules/core.md` 개정은 전 팀원에 영향. 변경 diff 를 제안만 하고, 명시적 승인 없이는 절대 쓰지 않는다. 승인 시 upstream PR.

자동 적용 금지(L4/L5). 항상 제안 → 승인 → 적용 순서. 결과를 한국어로 간결히 보고한다.
